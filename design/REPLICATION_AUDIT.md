# INbox 原稿复原审计

2026-10-02。本轮重新读取六个 Figma 页面的设计上下文和截图，以原始节点、尺寸和素材生成网页，再绑定真实数据与交互。用户的 Figma 文件未修改。

## 上一版本遗漏与本轮修复

| 页面或控件 | 复原内容 |
| --- | --- |
| 全局 | 原稿侧栏、页面标题、编号、四格统计、细线、原始字号、图标与蓝色强调；恢复原稿各区域层级和间距。 |
| 总览 | 四个主题卡、双列六条收藏、原始媒体槽位、四项互动数据、记录编号和分页。 |
| 全部收藏 | 原稿 194px 卡片、批注条、标签行、批量操作、筛选条、网格/列表入口及分页。 |
| 主题合集 | 四个主题卡、286px 规则面板、840px 记录列表、规则编辑入口、计数和分页。 |
| 标签矩阵 | 四列三行矩阵、趋势值和关联线、彩色数值、252px 右侧详情、蓝色记录元数据、列表和分页。 |

文字、收藏数量、标签名称和状态来自当前数据。AI 标签每条最多 3 个、全库最多 16 个；支持编辑和合并，保护用户修改。固定四个主题分类，原稿新建合集入口的文字调整为“整理设置”。新增 AI 和 X 配置页沿用主界面的视觉语言。

## 验证范围

- 1440×1170 浏览器视口、默认 100% 字号：总览 12、收藏 10、合集 9、标签 9、队列 8，共 48 个关键节点的位置和尺寸与原稿一致。详细值见 [浏览器审计数据](browser-layout-audit.json)。
- 六页的 164 个可见图片加载正常，SVG 渲染尺寸与源文件固有尺寸相同。原始模板 156 个图片槽位与本地源素材一一对应，见 [素材审计](asset-audit.json)。
- 六页均已视觉核对并保留截图；内容页采用原始 1202px 工作区，正文会随替换内容改变高度。此项不宣称所有文字和像素完全相同。
- 查询、分页和阅读优先级提交通过浏览器验证；优先级刷新后仍保留。修复了隐藏字段 `name="id"` 遮蔽表单 ID、导致优先级和批注等表单无法分派提交的问题。
- AI 选项可切换正确地址、模型与协议；设置、筛选和弹窗没有可见的原生 select。文字放大后表单草稿保留，字号刷新后保留。
- `npm test` 21 项通过，`npm run check` 通过。外部 AI/X 在测试中使用模拟响应，尚未使用用户真实凭据验证。X 使用 [官方书签接口](https://docs.x.com/x-api/users/get-bookmarks)，支持正式 OAuth 2.0 PKCE 授权和分页同步。

窄窗口保留桌面结构，使用横向滚动；放大字号时允许文字所在区域增高，默认大小维持原稿布局。示例收藏不伪装成真实 X 同步记录，缺少互动数据时显示“—”。

## 本轮 AI 阅读功能增补

在原有首页搜索行加入“AI 提问”，内容页页头加入“全文翻译 / AI 总结 / AI 对话”；六页原稿模板和素材没有修改。AI 使用可收起的深色侧栏，设置新增快捷 prompt 与用量面板，延续绿色细线、黄色状态和蓝色来源元素；语言与范围使用现有自定义菜单。

38 项测试通过。浏览器在隔离数据目录和模拟服务中验证总结、翻译语言、文章问答、全库 / 标签 / 主题范围、来源数量、快捷 prompt 保存及调用、关闭重开、token 与余额预警；响应明确标注“模拟”，主库未加入测试 Key 或模拟回答。验证了 360×900 窄视口、200% 缩放下的关闭、输入、发送与语言菜单，修复侧栏溢出导致关闭按钮不可见的问题。尚未用真实 API Key 验证模型输出质量及服务商余额。
