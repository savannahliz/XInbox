# INbox

个人 X 书签与网页文章同步、整理与查询工具。按照用户提供的六个 Figma 页面实现，默认使用黑底、绿色、黄色和白色，并保留原稿的蓝色强调元素。

本机 demo：[打开 INbox](http://127.0.0.1:4318/)。没有连接账户或导入文章时显示 12 条明确标注的示例收藏（9 条阅读队列、12 个标签）。第一次导入真实文章后显示本机收藏库。首次启动有四步可跳过的使用引导，设置可重新打开。

## 启动

推荐 Node.js 26，也支持 Node.js 22.22.2 起的 22.x 和 24.15.0 起的 24.x。使用 Mozilla Readability 和 jsdom 提取网页正文。

```sh
npm ci
npm run dev
```

服务只监听 `127.0.0.1:4318`。这是本机单用户版本，尚未部署到公网。

## 页面与交互

- 总览、全部收藏、主题合集、标签矩阵、阅读队列、内容详情，以及新增的同步中心和终端设置。
- 首页和全部收藏提供 URL 全文导入；连接 X 后，档案库标题旁显示真实 `@username`，未连接时显示“未连接”。
- 查询正文、作者、标签和链接；中文分词与常用中英近义词扩展；分类、媒体和阅读状态筛选。
- AI 标签默认每条最多 3 个、AI 标签池最多 16 个、每个最多 12 字；设置可修改数量、字数、复用偏好与整理要求，0 表示不限。保存后主动执行 AI 整理会重新生成已有 AI 标签。手动标签没有数量或字数上限，不占 AI 配额，AI 不覆盖手动编辑；支持新建、编辑、重命名与合并。
- 设置可为每个标签自定义十六进制颜色，提供绿、黄、蓝、白快捷色与恢复默认。颜色同步用于矩阵、收藏卡和内容页，重命名继承颜色，合并保留目标颜色；本机网页的颜色在切换 X 账户后仍保留。标签较多时矩阵与卡片自然延展。
- 未配置 AI 时使用本地规则，并明确显示“本地规则”。四个主题分类也使用本地规则，可手动修改。
- 内容页保留原文换行、空行与缩进，查看完整原文、配图及资源链接，编辑批注、标签、归档主题和阅读优先级；支持已读状态、相关收藏和上一篇/下一篇。
- 内容页提供 AI 全文翻译（中文 / English）、全文总结，以及可弹出 / 隐藏的 AI 对话侧栏。长文分段处理，显示实际进度；已完成结果及对话保存在本机。
- 翻译、总结与问答侧栏支持拖动左侧边缘、左右方向键微调。宽度在浏览器中保存，默认 480px、桌面 320–960px；全局缩放或窄窗口下按可用宽度收缩。
- 首页“Ask Agent”可选择全库、特定标签或主题合集；覆盖所选范围全部已保存的文字正文，并提供来源记录入口。
- 设置可新建、编辑、删除自定义 prompt，绑定唯一快捷词；在对话中点击快捷词或输入 `/快捷词 问题`，再发送。`Cmd/Ctrl + Enter` 发送，`Esc` 隐藏侧栏。
- API 用量显示当前 Key 在 INbox 的请求数、输入 / 输出 token；可设置本机 token 预算与剩余比例预警。DeepSeek 支持读取账户余额及低余额提示。
- 阅读优先级为 P0 今天优先、P1 近期阅读、P2 有空再看，也可不设置；卡片、详情、队列和批量标签编辑支持修改，队列可筛选或排序。批量标签默认追加，留空保留原标签，可明确选择替换。修改保存到本机 SQLite。
- 绿黄终端、霓虹都市、紫电黄光、琥珀电路四套配色；可自定义背景、面板、主色、辅色和文字颜色。配色保存在当前浏览器。
- 字号提供 100%、115%、130%，在当前浏览器保存；默认 100% 对齐原稿。设置、筛选和编辑弹窗使用统一的深色细线菜单，替代系统原生下拉菜单。
- 全局大小支持 50%–200% 的自定义整数比例，文字、图标、按钮、卡片、间距和弹窗同步缩放；提供 75%、100%、125%、150% 快捷选项和恢复 100%，刷新或切换页面后保持选择。
- 页面切换使用相同侧栏与工作区外框；总览的公共标题和统计字号与其他索引页一致。8 个页面、150% 全局缩放及 130% 字号下已检查外框尺寸不会随切换改变。
- 总览、全部收藏、合集记录和标签记录使用统一分页：上一页、下一页、输入页码跳转；第一页和末页禁用越界翻页，筛选后自动校正页码。
- JSON 导出、键盘焦点和 `Cmd/Ctrl + K` 查询快捷键。保留原稿配色与界面形式，较窄桌面窗口或全局放大时统计、筛选和卡片自动换行。

## 导入网页全文

在首页或全部收藏点击“导入 URL”，粘贴公开文章链接。公众号按 `#js_content` 保存完整正文；普通网页优先保留明确的文章容器，再由 Readability 提取。全文不受 AI 整理时 6000 字输入上限影响。保留段落、标题、引用、代码和图片顺序，详情页会随长文延展。

如果微信要求验证、网页要求登录或抓取失败，不会把验证页或摘要当成全文入库。本人在浏览器完成验证并打开全文后，另存为网页 HTML；在相同入口展开“网页需要验证？从 HTML 文件导入”，填写原始链接并选择保存的 HTML 文件。文件内仍需有实际正文，原帖已删除或只保存验证页时无法恢复。

请求使用明确的 `INbox/0.1` 标识。遇到微信验证立即停止，不使用代理池、验证码破解、自动验证码操作或反复更换请求身份。

正文图片尽量下载到 `data/media/`，与全文一起供本机阅读。支持常见栅格图片和内嵌图片；每张最多 6 MB，每次最多尝试 80 个不同地址，失败图片显示原图入口和实际计数，正文仍完整保留。HTML 最大 8 MB，过大文件明确报错，不保存截断内容。重复导入同一最终 URL 会更新正文，并保留批注、标签、分类和阅读队列。

不需要先连接 X；网页收藏独立存于本机，连接或切换 X 账号后仍然保留。源网页脚本不执行，只显示提取出的文本与缓存图片。下载前校验公开地址、重定向与 DNS，并固定已验证 IP；遇到 VPN 的 `198.18/15` 假 IP 时，使用 Cloudflare DNS-over-HTTPS 查询该域名的公开记录，不允许访问内网。该兼容查询只发送域名，不发送文章内容或完整 URL。

实际普通网页验证已保存 MDN 的 10,262 字正文和 2 张图片。用户提供的公众号样本返回微信验证页，尚未取得其真实全文；公众号解析与 HTML 回退使用合成图文样本验证，不代表该原文已导入。

## 连接 AI

### Jev 标签与归类

在“终端设置”的 Jev 面板选择 Vercel AI Gateway 或 TypeSafe，保存 API Key，再测试连接。`vck_` Key 使用 Gateway 的 [TypeSafe 兼容评估接口](https://vercel.com/docs/ai-gateway/sdks-and-apis/typesafe)。Gateway 若返回需要有效信用卡验证，需本人到 Vercel 控制台完成；应用不会显示为已连接。

启用后，导入网页、同步 X 和手动执行“AI 自动整理”均优先使用 Jev。一次请求同时判断主题分类与多个候选标签。默认提供 10 个宽泛中文候选，可自行修改；根据“优先复用已有标签”设置加入已有词汇，候选池与输出遵守 AI 标签数量和字数规则。低概率的标签不保存，低置信分类进入“待确认”。保留用户手动标签与分类，包括整理过程中进行的修改；整轮失败不部分覆盖已有内容。

Jev 接收标题和正文前 6000 字，原文完整保存。相同内容、规则与候选的结果按账户和收藏缓存；候选减少且仍包含已选标签时可继续复用。修改规则、添加候选、改变内容或更换 Key 会重新判断。缓存命中不调用模型、不重复消耗 token。页面显示实际请求数、输入/输出用量与本次缓存命中；未返回用量的失败请求单列，不冒充零消耗。预算预警按各接口 Key 在本机的累计用量分别计算，预算阈值共用设置。

Jev 用于从给定选项做判断，不生成新的标签名称或自由文本；翻译、总结与问答仍由以下生成式模型处理。关闭 Jev 后恢复原有模型整理，两个接口均未配置时继续使用本地规则。默认阈值（标签 0.75、分类置信度 0.6）尚未根据用户实际收藏校准，支持手动纠正。不预估或声称固定比例的 token 节省。

### 生成式模型

在“终端设置”选择服务，填写模型和 API Key，保存后点击“测试连接”，再执行“AI 自动整理”。完成 X 同步时也会自动整理新内容。

提供 OpenAI/Codex、DeepSeek、豆包（火山方舟）和其他兼容 API。OpenAI 使用 Responses API；DeepSeek、豆包使用 Chat Completions。豆包需填写自己可用的 Model ID 或 Endpoint ID。自定义接口可选择两种协议。

Quick AI 使用 API Key；Ask Agent 的 Codex 模式使用本机 Codex 登录。接口与模型预设依据 [OpenAI 模型文档](https://developers.openai.com/api/docs/models)、[Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create)、[DeepSeek 文档](https://api-docs.deepseek.com/quick_start)及[火山方舟文档](https://docs.volcengine.com/docs/ark/base-url-and-authentication?lang=en)。模型可在表单里修改，实际可用性以账户权限为准。

整理时会将收藏标题和正文发送到所配置的 AI 服务；长正文每条发送前 6000 字。每批 8 条，按当前规则验证返回的 ID、标签数量和 AI 标签池上限；整个整理任务通过后再保存，失败保留原标签并显示实际错误。

### 阅读与全局问答

新增翻译、总结和问答使用同一模型连接。全文翻译每段最多 3000 个 Unicode 字符，按原文顺序合并译文；完整保留原文及配图。总结和问答会读取全文，长文章 / 大收藏范围先按段提取相关信息，再逐层合并材料，没有只取开头或前几条记录的限制。处理大范围可能产生多次模型请求，可在侧栏点击“停止”。停止或失败时，已完成译文保留并标记为部分结果；模型返回截断输出时不将其标为完整结果。

对话依据已保存的文字，不分析配图或重新访问原文；答案附带所选来源入口，具体引用和准确性仍取决于模型。后续提问附带同一范围最近 6 条聊天消息（每条最多 2000 字），全文资料本身不会因此截断。对话按收藏账户和提问范围隔离；原文更新后使用新的内容对话，不复用旧译文。关闭侧栏不停止后台任务，重开可查看结果。重启服务会中断运行中的任务，已完成内容仍保留。

自定义 prompt 默认提供“总结 / 行动 / 解释”，每个最多 6000 字，快捷词为 1–16 个文字、数字、`_` 或 `-`，最多 32 个。指令与对话存于本机 SQLite。

### 用量与预警

模型用量取自 Responses API 或 Chat Completions 实际返回的 `usage`，包括标签整理、连接测试、翻译、总结和问答。输出截断但接口返回用量时仍计入。没有返回用量的请求单独计数，不按零消耗冒充已知；这时本机预算余量只表示上限。统计从此功能启用开始，按 API 地址及 Key 分开，不包含其他应用消耗或历史账单，不估算货币费用。

本机 token 预算默认关闭（填写 0），预警默认剩余 20%；预算是按累计 token 计算的本机提示，不会停止请求，也不是服务商充值额度。账户余额预警默认 5 CNY / USD。[DeepSeek 官方余额接口](https://api-docs.deepseek.com/api/get-user-balance/)可手动刷新，显示币种和读取时间；失败保留上次值并明确标注。其他当前适配接口显示“未提供可读取余额”，使用本机预算预警。没有配置 Key 时不生成假回答、假用量或假余额。

## X 一键授权

INbox_X 的公开 Client ID 已写入 `src/application-config.json`，普通用户只需在同步中心点击「连接 X」。桌面版打开系统浏览器的 X 官方授权页面，用户自行登录并授权；回调使用 S256 PKCE 获取令牌，无需 Client Secret。授权失败会显示回调、令牌交换或账号读取的阶段与公开错误原因。成功后显示用户名、状态和上次同步时间，提供立即同步和断开连接。

发布应用须登记桌面回调 `http://127.0.0.1:4319/auth/callback`；开发网页使用 `http://127.0.0.1:4318/auth/callback`。Client ID 与 Callback URL 仅保留在 Advanced / 开发者设置。state 单次使用、十分钟过期，系统浏览器回调不依赖应用 WebKit 的 cookie。

只申请 `tweet.read users.read bookmark.read offline.access`，继续使用现有分页、去重、刷新令牌与限流恢复逻辑。断开连接删除本机令牌，保留已导入收藏。[X OAuth 官方文档](https://docs.x.com/fundamentals/authentication/oauth-2-0/authorization-code)

## Research Canvas 与 Ask Agent

收藏栏支持全文、标题、作者、摘要、标签与日期筛选；单击、Command 和 Shift 多选、鼠标框选、批量拖入。文章卡片只存 Record 引用，支持移动、分组、带文字的连线；双击在右侧 Reader 阅读全文。普通笔记与 AI Note 都可连接文章；Sources 定位到原始卡片。

Ask Agent 提供 Quick AI、Codex 与 DeepSeek Harness。Quick AI 调用现有模型 API，只读取选定上下文并回答。Codex 使用官方 `codex app-server`，DSH 使用本机 `dsh --profile acp`，支持创建 / 恢复 Session、流式状态、取消和权限确认；二者通过 INbox MCP 读取和整理资料。模型 Key 留空时 DSH 可复用 INbox DeepSeek Key 或 DSH 自己已有配置。运行程序需预先安装，设置显示检测状态和路径。

选择一篇或多篇文章后可比较、总结、综合、找共同点、找冲突或自由提问，回答可添加回白板。选择模式的上下文在 MCP 服务端限制为指定 Record IDs。Agent 修改标签、合集、队列、阅读状态或导入链接时先显示确认界面，拒绝或取消不会修改。

## INbox MCP

`npm run mcp` 提供标准 stdio 服务，直接复用同一 SQLite。11 个工具为 `search_records`、`get_record`、`list_recent_records`、`list_tags`、`list_collections`、`add_tags`、`create_collection`、`add_to_collection`、`add_to_reading_queue`、`mark_as_read`、`import_url`。搜索覆盖正文、标题、作者、摘要；完整内容由 `get_record` 读取。

当前 Codex 项目的 `.codex/config.toml` 已配置 `mcp_servers.inbox`，`codex mcp get inbox` 已验证生效；重新打开项目可加载新工具。保持 INbox 打开，修改确认会出现在 App。其他 MCP 客户端可从「终端设置 → 查看 MCP 配置」取得当前实际程序和数据路径。

## 数据与验证

### macOS 安装版

`dist/INbox-0.2.5-arm64.dmg` 适用于 Apple Silicon、macOS 14 及以上。打开后将 INbox 拖入 Applications。安装包包含原生 WebKit 窗口和 Node.js 26 运行环境，不依赖开发目录或系统 Node；这是本机临时签名构建，尚未经过 Apple 公证。

安装版数据库、文章图片和加密凭据放在 `~/Library/Application Support/INbox`，浏览器中的字号、配色、缩放和侧栏宽度由安装版自己的 WebKit 保存。本机已用 `library-location.json` 让安装版与当前开发 / MCP 指向同一数据目录，不建立第二份库；其他机器首次安装使用标准 App Support 目录。安装包仅包含程序、字体、素材、依赖与运行环境，不包含开发目录的数据库或密钥。

后台只监听本机 `4319`，退出 App 时一起停止。X 应用回调地址应登记为 `http://127.0.0.1:4319/auth/callback`。普通外部资料链接通过系统浏览器打开，X 授权流程在系统浏览器完成。JSON 导出使用 macOS 保存对话框。已实测独立启动、内容页、宽度调整、菜单、导出 12 条完整示例记录，以及退出后端口释放；真实 X 授权仍需本人登录并批准官方授权，Jev 调用仍待 Gateway 的信用卡验证。

构建命令为 `zsh scripts/build-dmg.sh`，会替换 `dist/INbox.app` 和 `build/desktop/image` 中的生成产物。使用本机 Swift 编译器、现有官方 Node 发行文件与 macOS 磁盘工具，验证代码签名和镜像校验，并生成 `.sha256` 文件。

数据位于 `data/`。API Key 和 OAuth 令牌通过 AES-256-GCM 加密后保存在本机，浏览器只接收配置状态。数据库和本机加密密钥限制文件权限；密钥同在本机，不能替代设备自身的访问保护。`.env`、`data/` 已加入忽略列表。
